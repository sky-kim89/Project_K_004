# 몬스터 장비 패시브

> **2026-09-10 구현 완료** — 특이 패시브는 5장 배정표에 쓰인 **12종**을 만들었다
> (허세·반동·급소 찌르기·외톨이·성벽·처형·무게추·광합성·터지는 몸·굶주림·잔불·복수).
> 3장의 나머지 8종(벼랑 끝·짝꿍·선봉·불씨 옮기기·얼음 깨기·도박사·유대·수집가)은 **예비**다.
>
> 각성은 **숨기지 않는다** (사용자 결정) — 몬스터 상세에서 맨 위에 반짝이며
> "대분열 (분열 + 분열)" 로 뜬다. 4-1 의 '숨김' 안은 버렸다. 특이 패시브 각성(4-3)도
> 만들지 않았다 — 특이 패시브는 장비에서만 나오고 장비마다 하나라 둘을 모을 길이 없다.
> 정본은 코드다: `PassiveAwakening.cs` · `SpeciesPassive.cs` · `MonsterGearCreator.PassivesOf`.

## 1. 확정된 규칙 (2026-09-10)

| 항목 | 결정 |
|---|---|
| 같은 패시브 두 개 | **무시** — 하나만 적용. 단 **각성표(4장)에 있는 것은 각성판으로 바뀐다** |
| 단계 패시브 | 공격력 증가 I 과 III 은 **다른 패시브** — 둘 다 적용된다. I + I 은 같은 것이라 하나만 |
| 표시 | 몬스터 상세 패시브 목록에 함께 넣는다. **6개를 넘으면 아이콘 모드**(그림만, 올리거나 누르면 설명) — 구현 완료 |
| 증식 | 분열·재조립은 세대 규칙(`MaxReproduceGeneration = 0`)을 그대로 따른다 |
| 켜지는 조건 | 칸이 열려 있고(품질) + 장비가 Lv4 / Lv5 일 때 |

> ⚠ 표시 경계를 8 이 아니라 **6** 으로 잡았다 — 8줄은 752px 로 칸(727)을 넘어
> 고유 스킬 칸이 없는 종족에서도 깨진다.

## 3. 특이 패시브 제안 ⚠ 컨펌 대기

**원칙 — 혼자서는 조건이 잘 안 맞거나 대가가 있고, 짝이 되는 옵션·종족·패시브를 만나야 값을 한다.**
난이도: ○ 스폰 때 굽기(쉬움) · ◐ 기존 사건 훅(보통) · ● 피해 계산(Burst) 수정(어려움)

### A. 조건이 맞아야 켜진다

| 이름 | 효과 | 짝 | 난이도 |
|---|---|---|---|
| 허세 | 체력 50% 이상일 때 공격력 +12% | 재생 · 흡수 · 방벽 (체력을 지킨다) | ◐ |
| 벼랑 끝 | 체력 30% 이하일 때 공격 속도 +40% | 불굴 · 흡수 (낮은 체력으로 버틴다) | ◐ |
| 외톨이 | 같은 라인에 아군이 없으면 공격력 +25% | 특성 '소수정예' · 트롤 같은 단독 탱커 | ◐ |
| 짝꿍 | 같은 라인에 같은 종족 5기 이상이면 공격력 +10% | 슬라임 · 고블린 물량 · 분열 | ◐ |
| 선봉 | 라인에서 가장 앞에 있을 때 받는 피해 −20% | 밀쳐내기 컨셉 · 이동 속도 | ● |

### B. 다른 옵션이 사건을 만들어 줘야 켜진다

| 이름 | 효과 | 짝 | 난이도 |
|---|---|---|---|
| 반동 | 넉백을 줄 때마다 체력 1% 회복 | 넉백 옵션 (밀쳐내기 컨셉 · 진흙 범벅) | ● |
| 급소 찌르기 | 치명타는 방어율을 무시한다 | 치명타 확률 (급소 컨셉) — 치명타 0 이면 무의미 | ● |
| 처형 | 체력 30% 이하 적에게는 치명타 확정 | 치명타 피해 (**산적 두건의 특이 옵션**) | ● |
| 광합성 | 스킬 사용 시 체력 5% 회복 | 쿨감 (술법 컨셉) — 스킬 없는 종족은 무의미 | ◐ |
| 불씨 옮기기 | 화상·중독 걸린 적을 때리면 피해 +15% | 독 슬라임 · 화염 · 역병 | ● |
| 얼음 깨기 | 둔화된 적에게 치명타 피해 +50% | 서리 · 치명타 확률 | ● |

### C. 죽음이 연료다

| 이름 | 효과 | 짝 | 난이도 |
|---|---|---|---|
| 복수 | 같은 종족 아군이 죽을 때마다 공격력 +2% (판마다 초기화, 최대 10) | 분열 (죽는 수가 두 배) | ◐ |
| 잔불 | 죽을 때 그 자리에 3초간 화염 지대 | 분열 · 재조립 (죽는 횟수) | ◐ |
| 터지는 몸 | 죽을 때 주변 적을 밀쳐 낸다 | 원거리 뒤 라인 보호 · 폭발 | ◐ |

### D. 대가가 붙는다

| 이름 | 효과 | 짝 | 난이도 |
|---|---|---|---|
| 성벽 | 이동 속도 −30%, 받는 피해 −15% | 넉백 · 가시 (앞줄 고정) | ● |
| 무게추 | 넉백을 받지 않는다, 이동 속도 −10% | 성벽 · 선봉 | ○ |
| 굶주림 | 공격 속도 +15%, 최대 체력 −10% | 흡수 · 포식 | ○ |
| 도박사 | 공격의 30% 는 피해 ×2, 30% 는 ×0.5 | 치명타 피해 (분산을 키운다) | ● |

### E. 장비 시스템과 엮인다

| 이름 | 효과 | 짝 | 난이도 |
|---|---|---|---|
| 유대 | 같은 **컨셉** 장비를 낀 종족 수 × 공격력 +2% | 컨셉 몰아주기 (장비는 한 마리만 끼므로 '같은 장비' 가 아니라 컨셉) | ○ |
| 수집가 | 이 몬스터가 낀 장비 레벨 합 × 체력 +0.5% | 레벨업 (Lv5 ×3 = +7.5%) | ○ |

**추천 1차 묶음 (8개)** — 짝이 이미 게임에 있는 것부터:
처형 · 급소 찌르기 · 반동 · 광합성 · 복수 · 잔불 · 성벽 · 유대

## 4. 각성 패시브 — 같은 패시브 두 개가 모이면 ⚠ 컨펌 대기

> 사용자 제안 (2026-09-10) — **숨겨진 이스터 에그**. 분열 두 개 → 대분열.

### 4-1. 규칙 제안

- **세는 곳은 셋이다** — 종족 선천 · 융합으로 배운 것 · 장비. 어디서 왔든 **같은 패시브 두 개**면 각성한다
  - 예: 슬라임(선천 분열) + 거인의 뼈대 Lv5(분열) → **대분열**
- 세 개 이상이어도 한 번만 각성한다 (삼중 각성 없음)
- 각성표에 **없는** 패시브는 1장 규칙대로 무시한다
- 단계 패시브(공격력 I + I)는 각성하지 않는다 — 스탯은 이스터 에그가 아니다
- **숨김** — 처음 켜지기 전까지는 어디에도 안 적는다. 처음 켜지면 몬스터 상세에 각성판 이름으로 뜨고,
  도감에 기록된다(발견 목록). 한 번 본 것은 그 뒤로 장비 상세에 "??? 와 겹치면 각성" 힌트를 준다

### 4-2. 조합 패시브 각성표

| 원래 | ×2 → 각성판 | 효과 |
|---|---|---|
| 분열 | **대분열** | 둘이 아니라 **넷**으로 나뉜다 (각각 체력 1/4, 크기 더 작게) |
| 재조립 | **불사의 뼈** | 확률 없이 **반드시** 한 번 일어난다 |
| 역병 폭발 | **역병 창궐** | 중독된 적이 죽으면 옆 적에게 중독이 옮는다 |
| 폭발 | **연쇄 폭발** | 폭발로 죽은 적도 한 번 터진다 |
| 연사 | **탄막** | 한 번에 **세 발** |
| 화염 | **업화** | 화상 걸린 적이 죽으면 주변에 불이 번진다 |
| 가시 | **강철 가시** | 되돌리는 피해가 방어율을 무시한다 |
| 방벽 | **난공불락** | 피격 방어율 버프 동안 넉백을 받지 않는다 |
| 재생 | **트롤의 피** | 재생량 두 배 |
| 생명흡수 | **흡혈귀** | 체력이 가득 차면 넘치는 흡수가 보호막이 된다 |
| 피의 각성 | **광전사** | 처치 누적 상한 두 배 |
| 무리 사냥 | **우두머리** | 처치 누적 이동 속도가 같은 라인 아군에게도 붙는다 |
| 서리 | **동결** | 같은 적을 세 번 맞히면 1초 얼린다 |
| 치유의 잔재 | **생명의 씨앗** | 회복한 아군에게 3초 재생이 붙는다 |
| 지휘 | **전쟁의 북** | 공격력에 더해 공격 속도도 오른다 |
| 신속 | **질풍** | 이동 속도가 오른 만큼 공격 속도도 오른다 |
| 튼튼함 | **거상** | 덩치 +15%, 넉백을 받지 않는다 |

### 4-3. 특이 패시브 각성표 (3장이 확정되면)

| 원래 | ×2 → 각성판 | 효과 |
|---|---|---|
| 처형 | **참수** | 처형 문턱 30% → 45% |
| 반동 | **되튀김** | 넉백을 줄 때 회복에 더해 넉백 거리만큼 추가 피해 |
| 복수 | **원한** | 누적 상한 10 → 25, 판을 넘겨도 유지 |
| 잔불 | **화장터** | 화염 지대 3초 → 6초, 지대 위 적 둔화 |
| 성벽 | **요새** | 받는 피해 −15% → −30% (이동 대가는 그대로) |
| 급소 찌르기 | **일격필살** | 치명타가 방어율 무시 + 치명타 피해 +50%p |

> ⚠ 각성은 **두 곳에서 같은 걸 얻어야** 켜진다 — 장비 한 칸을 '일부러 겹치는 데' 쓰는 선택이 된다.
> 일반 규칙(겹치면 무시)만 있을 때는 손해였던 선택이 숨은 보상으로 바뀐다.
