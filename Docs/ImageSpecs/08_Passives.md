# 08 · 원작 패시브 (몬스터가 쓰는 16장 P1 · 용사 전용 24장 P2)

경로 `Icons/Passives/passive_<Type>.png` · 제작 128 (논리 32) · 표시 48 · 72
보이는 곳: 몬스터 상세 — **카드 레벨이 여는 패시브**(종족마다 하나, 도감에서 `Lv4` 로 표시) · 용사(적) 상세 · 융합으로 배운 패시브

## 이 계열의 규칙

- **틀 = 짙은 회색 사각판 + 청동 테두리**(논리 2px, 리벳 없음). 판 색 전 장 동일.
  종족 패시브(청회 + 강철 리벳)와 **같은 목록에 이어 그려진다** — 판 색(회 vs 청회)과 테 재질(청동 vs 강철 리벳)로 갈린다.
- 이름은 원작(장군·병사) 말투지만, 몬스터가 쓰는 16장은 **몬스터 상세에서 몬스터의 것으로** 보인다 → 사람·기사 도구를 쓰지 말고 **효과**만 그린다.
- 용사 전용 24장은 **적(인간 기사단)의 것** — 은빛 판금·기사 투구·군기로 그려도 된다. 병사·장군이 나오는 효과는 "기사 하나 + 작은 병사들" 로 통일.
- 종족 패시브와 **같은 효과**가 있다(생명 흡수 ↔ 흡혈 공격 · 방벽 ↔ 방어 강화 · 무리 사냥 ↔ 처치 가속 · 피의 갈망 ↔ 처치 강화). 종족 패시브 일부는 **실제로 이 패시브 위에 얹혀 돈다.** 두 그림은 **같은 사물을 쓰지 않는다** — 아래 '구분' 열을 지킨다.
- 현재(공통): 판 색이 장마다 제각각(주황·초록·파랑·빨강), 글리프 재사용(모루·천칭·사람 셋·해골·`L=`)이 가장 심한 계열이다.
