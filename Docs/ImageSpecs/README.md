## 항목 읽는 법

```
### `파일 키` — 이름 · 분류
- 효과   : 게임 코드의 뜻 (그림이 이것과 어긋나면 그림이 틀렸다)
- 주제   : 화면 한가운데에 놓을 사물·장면 — 하나
- 규칙   : 반드시 있어야 할 특징 / 다른 그림과 가르는 법 / 금지
- 현재   : 지금 들어 있는 더미의 문제 (다시 그릴 때 되풀이하지 말 것)
```

- **주제는 하나다.** 보조 표식(Brief 3.4 — 해골=죽을 때 · 방패 조각=피격 시 · 칼=처치 시 · 주먹=평타 시 · 위 화살표=지속 증가)은 주제가 아니다.
- **색**은 주제의 주조색이다. 판·테두리 색은 계열 규칙(Brief 4.1)이 정한다 — 항목마다 바꾸지 않는다.
- '짝' 이 적힌 항목은 **함께 놓고** 그린다 (원본↔각성판, I·II·III 단계, 같은 뜻의 다른 계열).

## 지금 더미 전체에 공통인 결함 (전 계열 반복 금지)

전부 `IconArt` 조합 키트(배경 6 × 테두리 5 × 글리프 28)로 찍은 것이라 같은 결함이 모든 계열에 있다.

1. **같은 글리프 재사용** — 모래시계 하나가 `쿨감 I~III · 재생 · 트롤의 피 · 기다림의 미학 · 대기만성` 에, 교차 칼(X)이 `분열 · 대분열 · 휩쓸기 · 반동 · 측면 · 주공 · 피격 반격` 에, 톱니가 `공속 I~III · 속성` 에 쓰였다. 뜻이 다른데 같은 그림이다.
2. **뜻과 무관한 글리프** — `분열` 이 교차 칼, `무게추` 가 모루, `흡혈귀` 가 물방울, `왕의 분열` 이 왕관만. 이름을 알아야 읽힌다.
3. **계열 표식이 안 보인다** — 종족 패시브의 리벳 테두리는 모서리 점 4개뿐이고, 판 색이 장마다 달라(주황·청·빨강·초록) 오히려 판 색으로 계열이 갈려 보인다. 새 그림은 **판 색을 계열마다 하나로 고정**한다.
4. **보조 표식이 너무 작다** — 오른쪽 아래 원 안의 기호가 48px 에서 점이 된다. 논리 10×10 칸, 외곽선 포함으로 키운다.
5. **배경의 사선 줄무늬·방사광** — 판 위의 줄무늬가 주제보다 눈에 띈다. 판은 **단색 + 가장자리 어둡게** 정도로 조용하게.
6. **시너지와 개성이 닮았다** — `sperk_NatureRestore` 가 `synergy_Forest` 와 같은 초록 동심원, `sperk_PackBond`·`sperk_Muster` 가 `synergy_Swarm` 과 같은 실루엣 셋. 같은 화면(소환사 정보·하단 카드)에 함께 뜬다.
