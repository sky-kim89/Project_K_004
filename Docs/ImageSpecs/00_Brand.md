# 00 · 게임의 얼굴 (P0 · 4장)

이 넷은 플레이어가 게임을 **처음 보는 순간**에 있다. 지금 넷 다 원작(픽셀 히어로)의 것이거나 코드로 그린 판이다.
공통: 진영을 뒤집어 그리지 말 것 — **몬스터 = 아군(왼쪽 → 오른쪽)**, **용사 = 적(오른쪽 → 왼쪽)**, 성은 **마왕성**이다.

---

### `Assets/Resources/Icon/Icon.png` — 앱 아이콘
- 파일: 2048×2048 (제작 1024 = 논리 256 ×4 → ×2 nearest). 같은 경로에 덮는다.
- 주제: 흉벽 위에 선 **소환사**(후드 로브, 한 손을 앞으로 뻗어 보라 마나를 뿜는다) + 그 손끝 앞 **보라 마법진**에서 튀어나오는 몬스터 셋(슬라임 · 고블린 · 스켈레톤, 전부 오른쪽을 향해 돌진).
- 규칙
  - 48px 에서 **덩어리 둘**로 읽혀야 한다: ① 소환사 실루엣 ② 마법진의 보라 빛. 몬스터 셋은 세 번째 층의 재미다 — 크기로 소환사를 이기지 않는다.
  - 배경: 짙은 남보라 밤하늘 + 마왕성 첨탑 실루엣(검은 보라). 하늘 채도를 낮춰 마법진 빛이 가장 밝은 점이 되게.
  - 네 변 10% 는 잘려도 되는 여백 (OS 가 모서리를 깎는다). 둥근 모서리·테두리·액자를 그리지 않는다.
  - **글자 없음.** 스토어가 이름을 옆에 적는다.
  - 몬스터는 게임 속 생김새를 따른다 (슬라임 = 노란 반투명 젤리 · 고블린 = 초록 피부 뾰족귀 · 스켈레톤 = 뼈색 두개골). 귀엽게, 2~3등신.
- 금지: 용사를 주인공으로 두기 · 원작의 붉은 망토 기사 · 오크와 기사가 맞붙는 구도 · 오른쪽 아래 반짝이 마크.
- 현재: 원작 "픽셀 히어로 / PIXEL WARS" — 글자가 두 줄, 주인공이 용사, **오른쪽 아래에 이미지 생성 도구의 ✦ 워터마크.** 전부 교체.

### `Assets/_project/3.Textures/BG/BG.png` — 스플래시 키 아트
- 파일: 2560×1440 (논리 640×360 ×4). 같은 경로 (지금 2724×1536 — 크기가 바뀌어도 된다).
- 주제: 위에서 비스듬히 내려다본 전장 — **왼쪽 1/3 마왕성 성벽**(세로로 뻗은 돌 성벽, 흉벽 위에 소환사 하나) · 성벽 바로 앞 마법진 3~5개에서 **몬스터 부대가 쏟아져 오른쪽으로 진군** · 오른쪽 1/4 에서 숲을 빠져나오는 **용사 부대**(은빛 판금 · 붉은 망토 · 방패) · 가운데에서 두 무리가 막 부딪히기 직전.
- 규칙
  - 시점·밀도는 `BG5.png`(전투 배경) 와 같다. 바닥은 흙 + 풀. 위쪽 하늘 띠는 좁게.
  - **위쪽 가운데 35%(가로 25~75%) 는 비워 둔다** — 로고가 선다. 하늘·먼 숲 정도만.
  - **아래 15% 는 차분하게** — 진행 막대와 버전 글자가 선다. 어두운 풀밭 정도.
  - 몬스터 무리는 종족이 섞여 보여야 한다 (슬라임·고블린·스켈레톤·좀비·늑대·오크·트롤). 한 종족만 그리면 "슬라임 게임" 으로 읽힌다.
  - 가장 밝은 점 = 소환사 손의 보라 빛과 마법진들. 용사 쪽은 그보다 어둡게.
- 현재: 원작 그림 — 왼쪽이 용사 군대, 오른쪽이 오크 무리. **진영이 정반대**다. 교체.

### `Assets/_project/3.Textures/UI/Lobby/title_pixel_general.png` — 로비 타이틀 엠블럼
- 파일: 760×600 투명 (지금 540×220 — 칸이 세로 300 이라 2배 여유로 만든다. UI 가 칸에 맞춰 늘리므로 세로가 넉넉해야 한다).
- 주제: 가운데 **마왕성 첨탑 셋**(가운데가 가장 높다) + 그 발치를 두른 **보라 마법진 링**(타원, 앞쪽이 아래로 휘게). 링 위로 작은 마나 입자 몇 점.
- 규칙
  - **글자 없음** — 게임 이름은 지금처럼 TMP 가 이 판 위에 쓴다. 그래서 **위쪽 40% 는 비교적 비워** 글자가 올라갈 자리를 남긴다 (첨탑 끝만 올라와도 된다).
  - 로비 사이드바(짙은 남색 면) 위에 뜬다 → 외곽을 어두운 남보라로 녹여 판 경계가 보이지 않게.
  - 스플래시 로고 자리에도 같은 그림을 쓸 수 있게 만든다 (사용자 확인 사항).
- 현재: 위에서 아래로 번지는 파란 그라데이션 판 + 파란 줄 — 그림이 아니다. 그 위 TMP 글자가 원작 "PIXEL …" 이다 (글자 교체는 사용자 확인 뒤).

### `Assets/_project/3.Textures/FortressWall_Vertical.png` — 마왕성 성벽
- 파일: 224×1280 (논리 56×320 ×4). **위아래가 이어 붙는 타일**이어야 한다.
- 주제: 위에서 내려다본 성벽 한 조각 — 왼쪽부터 성 안뜰 판석 → 성벽 몸통 윗면 통로 → 흉벽(총안) → 바깥면 → 그늘.
- 규칙 — **가로 픽셀 자리가 코드에 박혀 있다** (`InGameSceneSetup.cs`). 이 구간을 지키거나, 바꿨으면 상수를 다시 잰다:
  | x (px) | 무엇 | 그릴 것 |
  |---|---|---|
  | 0~85 | 안뜰 판석 — **소환사가 선다** | 어두운 판석(`#22222E` 에 가깝게 — 넓은 화면에서 그 왼쪽을 이 색 단색이 덮는다). 소환사가 올라서도 안 묻히게 채도 낮게 |
  | 85~90 | 성벽 안쪽 턱 | 어두운 선 |
  | 90~149 | 성벽 윗면 통로 — **라인 대기열 초상화가 얹힌다** | 밝은 돌길(그 위 UI 가 읽히도록 무늬를 약하게) |
  | 149~192 | 흉벽 · 총안 | 톱니 모양 흉벽, 사이사이 어두운 총안 |
  | **192** | **바깥면 — 용사가 멈추는 선** | 선명한 경계. 이 선에서 돌 색이 끊겨야 "벽에 막혔다" 가 보인다 |
  | 192~224 | 성 밖 그늘 | 바닥에 드리운 그림자 — 배경 흙 위에 반투명 대신 **어두운 흙색 불투명**으로 |
  - 세로 1280 안에 **흉벽 톱니 주기가 정수 번** 들어가야 타일 이음이 안 보인다 (예: 논리 16px 주기 × 20).
  - 마왕성답게: 검보라 돌 · 이끼 대신 균열 사이 보라 룬 빛 1~2곳 (반복 주기 안에서 한 번) · 해골 장식은 흉벽에 작게.
  - ⚠ 넣은 뒤 유니티에서 씬을 다시 구워야 반영된다 — **사용자가 한다** (Brief 8장).
- 현재: 회청 벽돌 무늬 + 오른쪽 검은 톱니 — 절차 생성. **플레이어의 체력 그 자체인데 가장 밋밋한 그림**이다. 마왕성으로 읽히는 요소(보라·해골·룬)가 하나도 없다.
