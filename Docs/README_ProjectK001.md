# Project_K_001
클로드 AI를 활용 하여 개발한 프로젝트입니다.
500 vs 500 정도의 대규모 전투를 상정하여 만들었습니다.
2026년 4월 초부터 약 2달간 하루 1~2시간 정도 작업하였고,
최근 8월 중순에 1주 정도 하루 8시간씩 집중 작업하여 마무리하였습니다.
케릭터 리소스를 제외한 모든 이미지 및 소스는 클로드 AI를 활용 하여 만들었습니다.
코드의 90%는 클로드가 작업하였고 전체적인 구조만 제가 잡고 진행 하였습니다.

**개발이 완료된 상태입니다.**

**현재 규모** — 액티브 스킬 32종 · 패시브 스킬 40종 · 장비 35종 · 어빌리티 46종 ·
특성 38종 · 시너지 14종 · 유물 29종 · 이벤트 14종

## 🎮 게임 진행 방식

1. **장수 선택** — 런 시작 시 기사·궁수·법사·방패병 중 장수 한 명을 선택합니다.
2. **배치** — 배틀 패널에서 장수를 배치 슬롯에 배치하고 용병 시장에서 추가 장수를 고용합니다.
3. **스테이지 도전** — 스테이지 1~30을 순서대로 자동 전투로 클리어합니다. 중간에 상점 스테이지와 이벤트 스테이지가 포함됩니다.
4. **성장** — 상점에서 특성을 구입하거나 이벤트에서 어빌리티·특성을 획득하여 런 내 전력을 키웁니다.
5. **실패 시 환생** — 스테이지를 클리어하지 못하면 즉시 환생합니다. 환생 시 획득한 환생 포인트로 유물을 해금하여 다음 런에 영구적인 이점을 얻습니다.
6. **반복** — 유물로 누적 성장을 쌓으며 더 높은 스테이지를 목표로 런을 반복합니다.

## 📖 게임 설명

### 장수 (General)

장수는 전투의 핵심 유닛으로, 직접 싸우면서 병사를 이끌어 자동 전투를 수행합니다.

| 항목 | 설명 |
|------|------|
| **직업** | 기사(균형·고이동), 궁수(원거리·고공격), 법사(최고공격·저체력), 방패병(최고방어·체력) |
| **등급** | Normal → Uncommon → Rare → Unique → Epic (등급마다 스텟 배율 상승, 패시브 슬롯 증가) |
| **패시브 스킬** | 등급에 따라 1~3개 슬롯 자동 적용 — 조건 없이 상시 발동하거나 특정 이벤트에 반응 |
| **액티브 스킬** | 쿨다운 기반으로 AI가 자동 판단하여 발동하는 강력한 스킬 (20종) |
| **장비** | 런 내 수집·강화 가능한 장비를 슬롯에 장착해 스텟 보강 (런 종료 시 초기화) |
| **어빌리티** | 런 중 보상으로 획득하는 특수 능력 — 런 종료 시 초기화 |
| **유물** | 환생 포인트로 해금하는 영구 성장 아이템 — 런이 끝나도 유지 |
| **특성** | 상점·이벤트에서 획득하는 런 내 버프 — 직업 특성과 공통 특성으로 분류 |
| **시너지** | 배치된 장수들의 직업 조합에 따라 자동 활성화되는 추가 버프 (14종) |

## 📚 시스템 상세 설명

### ⚔️ 스텟 (Stat)

장수와 병사의 전투력을 결정하는 수치입니다. 기본 스텟은 직업과 등급에 따라 다르며, 장비·패시브·어빌리티·유물·특성·시너지를 통해 강화할 수 있습니다.

| 스텟 | 설명 |
|------|------|
| 공격력 (Attack) | 기본 공격 및 스킬 피해량의 기준 |
| 최대 체력 (MaxHp) | 전투에서 버틸 수 있는 총 내구도 |
| 방어율 (Defense) | 받는 피해를 감소 (퍼센트 단위) |
| 이동 속도 (MoveSpeed) | 적에게 접근하거나 포지션을 잡는 속도 |
| 공격 속도 (AttackSpeed) | 일반 공격의 연사 빈도 |
| 사거리 (AttackRange) | 원거리 유닛의 공격 가능 거리 |
| 스킬 쿨다운 감소 (SkillCooldownReduce) | 액티브 스킬의 재사용 대기 시간 단축 |
| 치명타 확률 (CritChance) | 치명타 발생 확률 |
| 치명타 피해 (CritDamage) | 치명타가 터졌을 때의 피해 배율 |
| 병사 수 (SoldierCount) | 장수 소속 병사 인원 수 |
| 지휘력 (CommandPower) | 소속 병사 스텟 배율 보너스 |

### 🛡️ 패시브 스킬 (Passive Skill) — 40종

등급에 따라 슬롯이 주어지며(Normal/Uncommon=1, Rare/Unique=2, Epic=3) 전투 내내 효과가 유지됩니다.

**병사 강화 계열**
| 패시브 | 효과 |
|--------|------|
| 증원 병사 | 병사 수 추가 |
| 병사 전투 강화 | 병사 공격력·이동속도 % 증가 |
| 병사 군단 | 병사 수 대폭 증가, 대신 병사 공체 감소 |
| 전위 오라 | 병사 방어율 % 증가 |

**교환 계열** *(강점을 극단화하는 리스크 패시브)*
| 패시브 | 효과 |
|--------|------|
| 약한 장군, 강한 병사 | 장군 공체 감소, 병사 공체 대폭 증가 |
| 강한 장군, 약한 병사 | 병사 공체 감소, 장군 공체 대폭 증가 |
| 약한 장군, 더 많은 병사 | 장군 공체 감소, 병사 수 추가 |
| 광전사 계약 | 전체 공격력·공속 증가, 방어율 감소 |

**장군 강화 계열**
| 패시브 | 효과 |
|--------|------|
| 장군 전투 강화 | 장군 공격력·이동속도 % 증가 |
| 거인 장군 | 장군 크기·공체 증가, 공격속도 감소 |
| 지휘관의 분노 | 장군 크리티컬 확률·배율 증가 |

**시너지 계열** *(병사와 장군의 연계)*
| 패시브 | 효과 |
|--------|------|
| 병사 강화 장군 | 병사 수 × N% → 장군 공체 증가 |
