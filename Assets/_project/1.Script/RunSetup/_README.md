# RunSetup — 런 준비 씬 (v2 신규, 미구현)

기획서: `Docs/GameDesign.md` 1.2절

원작 `Lobby` 를 대체한다. 씬 구성: Splash → **RunSetup** → InGame.

- 캔버스 1080×1920 세로
- 흐름: 소환사 선택 → 몬스터 도감 편성 탭에서 소환 덱 구성 → 런 시작
- 런당 1회만 쓰므로 **상주시키지 않고 언로드해도 된다** —
  원작이 두 씬 상주를 택한 이유(로비 배경 연출, 전환 지연)가 여기엔 없다.
