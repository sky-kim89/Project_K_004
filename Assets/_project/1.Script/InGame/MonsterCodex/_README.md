# InGame/MonsterCodex — 몬스터 도감 (v2 신규, 미구현)

기획서: `Docs/GameDesign.md` 8.3절 · 4.5절

원작 `Data/Sections/CodexData.cs` 의 "수집 = 스탯 버프" 구조를 재사용하되,
**이 화면이 곧 소환 덱 편성 화면이다.** 해금 로그와 편성 화면을 나누지 않는다.

## 들어갈 파일
- `MonsterUnlockCondition.cs` — **조건부 결정적** 해금. 확률 뽑기가 아니다.
  예: "Hero Warlord N회 처치", "이벤트 선택지 X", "상점에서 소환 정수로 구매".
- 도감 UI (해금 탭 + 편성 탭)

## 반영 타이밍 규칙
- **수집 스탯 버프**(수집 종수 × 0.5%)는 원작 `LockForRun` 규칙 그대로 —
  여정 경계에서만 반영한다. 전투 중 스탯이 흔들리면 밸런스가 안 선다.
- **해금 자체**(편성 풀에 항목이 늘어나는 것)는 즉시 반영해도 된다 —
  스탯 변화가 아니라 선택지 추가이기 때문.
- 해금 상태는 **환생해도 유지**된다.
